Inline markup
=============

Some *emphasis*, some **strong text**, and an inline `literal`, all in
the same sentence.

See target_ for the definition, and _target marks it inline.

A named link: `Python <https://www.python.org/>`_ leads out.

Cross-document: :doc:`the guide <guide>` or plainly :doc:`guide`, and a
role of a different name: :ref:`elsewhere`.

Punctuation stays put: a-b, 3 * 4 = 12, (parens), "quotes", and a colon: like this.

A doubled backtick span, ``a literal with a lone ` backtick inside``, reads
as one literal, its open and closed backtick runs counted independently of
each other.
